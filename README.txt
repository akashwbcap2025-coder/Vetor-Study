VETOR — BVSc & AH learning hub
================================
Files:
- index.html: complete responsive static website
- assets/goat-sketch.png: goat pencil-sketch emblem

Run locally:
Open index.html in a modern browser. No build tools or database required.

Publish free:
1. Create a GitHub account (if eligible) and a new public repository named vetor.
2. Upload index.html and the assets folder, preserving the folder structure.
3. In repository Settings > Pages, choose Deploy from a branch, select main / root, and save.
4. GitHub Pages will provide a public website address.

Alternative: Netlify Drop can publish the unzipped folder as a static site, subject to its current account/age terms.

Ask AI:
The Ask AI tool copies a carefully framed study prompt and opens ChatGPT. The user pastes the prompt into ChatGPT. A ChatGPT Free account is not an API key; direct in-page AI answers require a separately configured backend/API and may incur usage charges. Never place a secret API key in public browser JavaScript.

Academic scope:
This is a bilingual starter learning library and syllabus map, not a complete authoritative textbook. It is mapped to the VCI MSVE Regulations, 2016. Universities may issue updated course catalogues, practical requirements and local variations. Verify against the official Gazette and your college's current curriculum. Expand each subject with faculty-reviewed chapter notes, diagrams, question banks and practical manuals before describing it as complete.
